# Construcción de UI

1. Antes de crear o modificar cualquier pantalla o componente de React, leé y seguí `.agents/skills/ui-builder/SKILL.md`.
2. Usá primero los componentes estándar de `frontend/src/components/standard/`. Si falta algo, se agrega ahí (con test y en el catálogo de la skill), no se copia en la pantalla.
3. Si cambiás o creás un componente estándar, actualizá el catálogo de la skill en el mismo commit.
